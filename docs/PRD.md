# 产品概述

本项目是一款面向企业内部分析师的轻量化自助 BI 可视化平台，采用 Next.js + FastAPI 前后端分离架构，支持业务人员零代码完成数据接入、数据加工、可视化看板搭建与数据分享导出。

平台摒弃传统 BI 重型架构，以 MVP 最小可用闭环为设计原则，仅保留自助分析核心链路：

- 内置 Mock 数据与 CSV 文件上传两种数据源
- 通过数据集完成字段别名定义、数据过滤与口径统一
- 拖拽式画布搭建柱状图、折线图、饼图、数据表格
- 看板全局筛选联动、只读分享与 PDF 报表导出
- 基于角色的分级权限：管理员 / 分析师 / 查看者

项目聚焦自助 BI 核心技术难点：拖拽画布 JSON 结构化存储、通用图表数据适配器、全局状态联动渲染。二期（多数据源接入、AI 智能问答、数据下钻等）暂不实现。
